MontaFácil

Política de Privacidade

Última atualização: 19 de abril de 2026

1. Introdução

O MontaFácil é um aplicativo de gerenciamento de serviços e agendamentos para montadores de móveis. Esta Política de Privacidade descreve como coletamos, usamos e protegemos suas informações ao utilizar o aplicativo.

2. Dados coletados

O aplicativo pode coletar e armazenar as seguintes informações:

  • Dados de conta: nome e e-mail para autenticação (login via Google ou Apple).
  • Dados de clientes: nome, telefone e endereço inseridos manualmente pelo usuário.
  • Dados de agendamentos: data, horário, tipo de serviço, valores e observações.
  • Fotos: imagens de móveis associadas a agendamentos, armazenadas localmente no dispositivo.
  • Contatos do dispositivo: acessados apenas para importar clientes, mediante permissão explícita.

3. Como usamos os dados

  • Gerenciar agendamentos, clientes e serviços do usuário.
  • Gerar orçamentos em PDF e relatórios financeiros.
  • Enviar lembretes e mensagens via WhatsApp (iniciados pelo próprio usuário).
  • Realizar backup e sincronização dos dados entre dispositivos (quando ativado).

4. Compartilhamento de dados

Não vendemos, alugamos nem compartilhamos seus dados pessoais com terceiros. Os dados são armazenados localmente no dispositivo e/ou em servidores seguros utilizados exclusivamente para o funcionamento do aplicativo.

5. Permissões utilizadas

  • Contatos: para importar clientes do dispositivo (opcional).
  • Notificações: para alertas de agendamentos e atualizações do app.
  • Câmera / Armazenamento: para adicionar fotos aos agendamentos.

6. Segurança

Adotamos medidas técnicas e organizacionais para proteger seus dados contra acesso não autorizado, perda ou alteração. A autenticação é realizada via provedores seguros (Google/Apple).

7. Retenção e exclusão de dados

Os dados ficam armazenados enquanto o aplicativo estiver instalado. Ao desinstalar o app ou solicitar a exclusão da conta, todos os dados locais são removidos. Para solicitar exclusão de dados em servidor, entre em contato pelo e-mail abaixo.

8. Crianças

O MontaFácil não é destinado a menores de 13 anos e não coleta intencionalmente dados de crianças.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. Notificaremos o usuário por meio do aplicativo em caso de mudanças relevantes.
