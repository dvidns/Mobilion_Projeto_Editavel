# Mobilion — Etapa 1
Projeto original preservado, com alteração no menu inferior:
- Hoje
- Agenda
- Atender (tela de clientes existente)
- Gestão (tela Mais existente)
A tela Despesas continua acessível pelas rotas existentes, mas foi removida da barra inferior.

Esta entrega NÃO inclui sincronização com Google Contacts/Calendar ou Firebase. Essas funções exigem credenciais OAuth, configuração de projeto Google Cloud e testes. Não declare integração ativa antes de configurar e testar.

Abra o projeto no VS Code. Execute npm install e npm run check no seu ambiente com Node.js; a compilação Android não foi testada aqui.
Faça backup dos dados antes de instalar qualquer atualização. A estrutura original do banco não foi alterada.
